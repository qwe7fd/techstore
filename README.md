# TechStore

Современный интернет-магазин электроники, построенный на React и Vite.

## Возможности

- Каталог товаров с фильтрацией по цене и рейтингу
- Сортировка товаров (по имени, цене)
- Детальные страницы товаров с галереей изображений
- Корзина покупок на сервере (у каждого пользователя своя, переносится при входе)
- Промокоды (попробуйте `SAVE10` для скидки 10%)
- Адаптивный дизайн для всех устройств
- Похожие товары на странице продукта

## Технологии

- React 19.2.0
- Vite 7.3.1
- React Router 7.13.1
- Tailwind CSS 4.1.18
- Lucide React (иконки)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## Структура проекта

```
src/
├── components/       # Переиспользуемые компоненты
├── pages/           # Страницы приложения
└── services/        # API-клиент и сервисы (auth, cart, products)
```

## Страницы

- `/` - Каталог товаров
- `/product/:id` - Детальная страница товара
- `/cart` - Корзина покупок
- `/login`, `/register` - Аутентификация
- `/admin` - Управление товарами (только роль admin)

## Подключение к API

По умолчанию фронт ходит на прод: `https://techstore-api-mdzs.onrender.com/api`.

Для локального бэкенда (в репозитории back: `docker compose up --build`, затем сид):

```bash
cp .env.example .env.local   # VITE_API_URL=http://localhost:3000/api
npm run dev                  # перезапустить dev-сервер, если уже запущен
```

`.env.local` в git не коммитится. Проверить, куда ходит фронт, можно в DevTools → Network.
